Everything as code

Connectors, detections, playbooks and AI prompts live in GitLab. Changes go through MR review, tests and CI/CD, and git keeps the full history.

No event loss

SQS buffers ingestion and orchestration, so they survive orchestrator outages. Raw-event backups and DLQs allow replay. Failures are routed to error branches and alerted, never silently marked as success.

Humans in the loop

Auto-closure requires a deterministic external fact, and each class runs in shadow mode before go-live. Actions with consequences are enabled explicitly, and every automated step is visible in the ticket.

Case Studies

Selected work

Anonymized production systems.

Architecture

Enterprise SOAR on top of existing tools

Challenge
The business had already standardized on its ticketing system and a low-code orchestrator. Neither is an enterprise-grade SOAR on its own.
Approach
Designed a custom core around them: an API layer with queue-based workers, buffered event ingestion, a playbook format resolved at runtime per detection, and configurable approval rules.
Orchestrator outages lose no events. A new detection automatically gets a ticket, dedup, severity and AI triage. A new playbook is one file in Git.
Insider risk · Compliance

Monitoring employee access to client PII

Challenge
Regulators and the business needed evidence that staff access to client data is controlled. Static thresholds were too noisy.
Approach
Access events from internal systems are scored by static rules plus a behavioral model with personal and peer-group baselines. Alerts land in case management, and analyst verdicts feed back into the platform.
Full cycle from detection to triage, verdict and a weekly report for management.
AI · SOAR

Self-improving AI triage

Challenge
Analysts spent the first tens of minutes of every alert gathering context by hand.
Approach
AI agents with read access to the SIEM and case data post an enriched first verdict and follow up on new comments. Analyst decisions become feedback, and the system periodically proposes prompt improvements for review.
First triage within minutes and substantially less analyst time per alert. Agents cannot change their own behaviour; every change is human-reviewed.
DLP · Automation

Secret exposure with content verification

Challenge
DLP secret-exposure alerts were mostly false positives, but the real ones were critical.
Approach
A detection flags the exposure, then an LLM checks whether the content is a real secret. False positives close automatically. For real hits, the employee is notified directly and the case escalates if needed.
The majority of the alert class was auto-closed from the first day in production.
Guardrails

Auto-closure with a deterministic gate

Challenge
Auto-closing alerts on an LLM opinion alone is not acceptable in a regulated company.
Approach
AI proposes the verdict, but closure requires an independent fact: a matching access approval, a privileged-access session record or verified content. Each alert class runs in shadow mode before it goes live.
Most alerts in covered classes close automatically, with a full audit trail in every ticket.
Insider risk

Leaver watch

Challenge
Departing employees are a well-known data-exfiltration risk window.
Approach
HR offboarding data flows into enrichment automatically. Flagged users get a dedicated rule set and AI-reviewed activity monitoring, routed to the SOC.
Heightened monitoring kicks in automatically from HR data, with no manual watchlists.
